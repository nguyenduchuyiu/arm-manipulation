# Figure captions and provenance

All figures are generated by code. SVG retains editable text; PDF uses embedded TrueType fonts. PNG previews are 240 dpi.

## 01_voxel_workspace

Original detailed arm STL visuals at the recorded home pose, surrounded by the exact exposed boundary of the dynamically validated 2 cm voxel map. Transparency is used only for visualization; no smoothed reachability hull is substituted. The robot web mesh is decimated; original geometry is supplied separately. This figure embeds a code-rendered 3D image; labels remain vector. Portable GLB assets are in assets3d/. Voxel interiors are not individually certified.
