Status: COMPLETE. No training or checkpoint changes.

Purpose: test spatial extrapolation beyond the support of the pick-data spawn sampler, rather than new draws inside the same rectangle. This does not establish extrapolation beyond reach pretraining.

Test: 8outside targets (x_low,x_high x four colors), paired with8inside controls. Both Y edges were excluded after100candidates each: y_low=-0.45m had no feasible visible pair; y_high=-0.07m had no successful original physical expert pair. See local e122_xy_preparation.json. Outside center is30mm beyond an edge; control center is30mm inside that edge. Other object positions, target yaw, color, camera, home and planning protocol stay matched. All distractors are inside the spawn rectangle. Each accepted initial scene must have a successful original physical expert grasp and a visible target in the original front camera. Rejected candidate pairs are recorded. No expert actions are provided to the model.

Pick-training world-frame bounds: X[0.30,0.78]m,Y[-0.42,-0.10]m. Actual train centers are audited independently from saved initial states. The complete target footprint lies beyond the selected X edge. Table, camera and physics are unchanged. Checkpoint selection was fixed before constructing this test.

Success: target lifted>4cm with bilateral jaw contact for10consecutive frames; wrong-object lift fails. No videos requested.
