## Frozen TCOW backbone → 25 Hz action flow overfit — 2026-09-28

Code: `memory_occlusion/experiments/tcow_flow_matching/run.py` and `infer.py`. The input is the 240×320 RGB video plus the target's ground-truth mask **only at frame zero**, along with current measured six-joint position. The preceding 10 Hz fine-tuned TCOW checkpoint is frozen. Its causal `tracker_backbone` output (768 channels, spatially pooled to 3×4) is used directly; neither the three-mask head nor the flag head is called. Every 25 Hz action frame uses the latest TCOW feature whose source video frame is at or before that action frame. TCOW uses independent 30-frame clips, each consisting of the original query frame and 29 consecutive 10 Hz observations; no recurrent state passes between clips.

The flow predicts eight future six-joint absolute actions at 25 Hz. It trains a rectified velocity field on joint-relative actions scaled by joint, with Gaussian source noise and uniform flow time, for 3,000 AdamW steps on four seed-0 episodes (Butter, Milk, Popcorn, Tuna). Inference integrates 16 Euler steps and clamps to normalized arm/gripper limits. Only windows whose eight expert actions are marked valid enter training and the offline metrics, yielding 1,279 windows per episode. The seed-8 Butter episode is excluded from the flow optimizer. All feature extraction, training and inference ran on local MPS.

### TCOW temporal context audit — 2026-09-29

The upstream `third_party/tcow` evaluation handles videos longer than its fixed 30-frame input by making separate clips from the query frame with different temporal strides (1–10 in `data/data_utils.py`). Its `QueryMaskTracker.forward()` consumes one clip and query mask; no state is returned for the next clip. Our TCOW + flow code instead chose the original query frame plus disjoint blocks of 29 consecutive 10 Hz frames. This is a custom inference/training scheme, not upstream full-video sampling. It preserves only the first query frame and the current block's 2.9-second visual trajectory inside TCOW. The flow's running mean of TCOW hidden features does not pass memory back to TCOW, and averaging loses temporal order.
