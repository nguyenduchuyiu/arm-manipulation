Initialize the original official TCOW RGB/query backbone, not a tracker fine-tuned in e100/e105/e106. All backbone parameters frozen; eval/no-grad throughout feature extraction. No segmentation head or attention pooling. Per endpoint cache only the current frame's [15,20,768] query-conditioned spatial tokens, flattened in row-major patch order to230,400 values. Backbone BF16; selected part's float16 features are persisted as disk-backed train_features.npy (~4.96GiB for part1) and val_features.npy, with labels train_xyz.npy/val_xyz.npy. A partial NPY from interrupted extraction is not a complete cache: require completed train_cache.json/val_cache.json and matching config/provenance. After extraction, release TCOW and RGB RAM cache, then load the entire train and validation feature arrays and all train targets onto CUDA once. CUDA-resident shuffled indices select batches; head training does not stream feature batches from host/disk. gpu_cache.json records actual residency, allocated VRAM and load time. The full unsplit cache exceeds GPU capacity, so current command selects --part1.

Train exactly Linear(230400,3):691,203parameters. Zero weights/bias initially predict the selected train part's coordinate mean. Fixed feature mean/std from train part only (std floor.01), divide by sqrt(230400) for optimization; this affine normalization is folded into exported `raw_xyz_head` weights/bias. Train-part-only XYZ mean/std with10mm std floor. Loss: normalized current-frame XYZ MSE only. No accumulation or gradient checkpointing. Head matmuls FP32/TF32. Cache inference batch32 (passed GPU preflight). No weights are continued across parts by this command.

Best checkpoint: lowest equal-weight mean of visible/shuffle/post_shuffle/exposed/lift mean Euclidean XYZ errors on fixed validation endpoints; evaluate each epoch. Initial mean-coordinate baseline, per-epoch losses, final best-head train fit and validation are recorded. `best.pt`, `latest.pt`, `final.pt` contain head and normalization/export weights; backbone is referenced by original source paths/hashes and is not duplicated. These are head checkpoints, not optimizer-resume checkpoints. Training and validation metrics do not establish manipulation success or full held-out generalization.
