# e108_context — shared ContextDecoder XYZ training with a surrogate wrist camera

Status: starting. Implement the user-proposed frozen TCOW + frozen ViT + measured-state -> ContextDecoder -> shared context -> auxiliary XYZ / reach-FM architecture. This experiment trains XYZ localization only. FM is present for interface verification and future BC, but all its parameters are frozen and there are no action-training updates or manipulation-success claims. Cam left is a temporary second-camera input, not an actual wrist-mounted camera.

Data: same part1 as e107,412query episodes/103contexts, all32train layouts/16seen permutations/4targets. Train context/expert endpoints stride25 plus segment terminal frames:11,568points. Validation: same32episodes/184phase endpoints, stride10, layouts32/33 and permutations0/9/16/18. Reuse the original-TCOW spatial token cache in e107_linear/train_3 (raw FP16 tokens before the linear probe's normalization,300×768per endpoint); no TCOW recache. Load cam-left current RGB at the exact same raw frame, original320×320, ImageNet normalize and frozen ViT-B/16 ->20×20patches ->8×8spatial pooling ->64×768tokens. Cache aligned cam-left features and measured6Djoint positions, with all cache arrays placed on GPU for training. No GT XYZ/object ID/mask/action labels enter the network; object identity is carried by TCOW's initial point-conditioned cached features. Labels are GT target XYZ in robot-base metres.

Architecture: separate trainable LN/Linear768→960projections and two view embeddings; concatenate300top tokens,64left tokens,one reach-pretrained measured-state token. Existing OATFlow ContextDecoder:4bidirectional self-attention blocks,width960,365input/output tokens, gradient checkpointing disabled. It retains all spatial tokens. XYZ head: LayerNorm960per token,flatten365×960,Linear350400→3; new random readout, initial weight std1e-4/bias0. Training-only XYZ mean/std from part1, stdfloor10mm. Shared context also interfaces with all8K/V projections of the16block reach-trained FM. Preserve10DEE-delta/rotation6D/jaw action representation and original FM normalization; do not use the separate absolute-joint policy branch.

Frozen: original official TCOW RGB/query weights; ImageNet ViT-B/16; every reach FM/state encoder parameter. Trainable: both visual projections,view embeddings,all4context blocks,XYZ head. No e107linear-head or e105/e106fine-tuned weights initialize this run. Context seed108. Loss: normalized currentXYZ MSE only,weight1. Initial training budget30epochs, physical batch128(selected by measured VRAM),91updates/epoch,2,730updates total, small final batch retained, no accumulation/checkpointing. AdamW(.9,.95),wd1e-4,gradclip1; projections/contextLR1e-4,XYZ headLR1e-5,warmup50updates then cosine to10%. Actual batch,counts,timing,trainable parameters and hashes in each run's config.json.

Preflight: use complete selected-part GPU cache, several real training updates; check finite nonzero gradients in every trainable module, unchanged frozen modules/no gradients, no gradient checkpointing,365-token output,8K/V context sets, and finite H25×10Dreach-FM inference. This does not test action quality. Preflight budget/results recorded separately. Main validation each epoch; select best equal-weight mean of five phase means (visible/shuffle/post_shuffle/exposed/lift). Log normalized loss and currentXYZ error in mm. Save only trained context/projection/readout weights plus XYZ normalization; reference frozen source weights by hashes instead of duplicating them.

Evaluation: report train fit, validation mean/median/p90/thresholds and phase errors. Probe post-shuffle target binding by swapping TCOW target-conditioned tokens across the four queries of the identical context, retaining the same left/state inputs. Separate held-out XYZ test uses32unseen-order,32unseen-layout,32both cases at fixed phase endpoints; no robot-control rollouts, H/K/noise budget not applicable except synthetic FM interface preflight. Held-out test status initially not run; no results until completed. Exact point manifests and predictions are saved.

Artifacts: cache/config.json and aligned NPY arrays; preflight/config.json; train/config.json,progress.json,metrics.jsonl,validation.jsonl,best.pt/latest.pt/final.pt,summary.json; test_xyz/config.json/summary.json after evaluation. Every stage has its own README and tee log in tmux ssh_tmux:1. Canonical notes: docs/research/e108_context.md. Cache phase and test phase are not training. This uses a static surrogate left camera, not wrist-camera robustness evidence.
